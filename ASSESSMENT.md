# Assessment

## Weighting
- Weekly lab checkpoints: **20%**
- Six common homeworks: **30%** (5% each)
- Common final blind project: **40%**
- Oral scientific defence: **10%**

## Rubric dimensions used throughout
1. Scientific formulation
2. Statistical correctness
3. Uncertainty quantification
4. Diagnostics and failure analysis
5. Reproducibility
6. Scientific interpretation

High accuracy with leakage, invalid splitting, selection bias or uncalibrated uncertainty is not a strong result.

## Commonality
All students receive the same homework questions and the same final-project train/blind files. Collaboration rules can follow local Faculty regulations, but submitted analyses must be individually authored unless the instructor explicitly defines group work.
